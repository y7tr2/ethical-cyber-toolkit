# Ethical Cyber Toolkit

مجموعة تعليمية دفاعية تحتوي على 210 مثال بايثون للعمل على Termux والكمبيوتر.

## الاستخدام المسؤول

شغّل هذه الأمثلة فقط على جهازك أو على نظام لديك إذن مكتوب لاختباره. هذه المجموعة لا تحتوي على استغلالات أو سرقة بيانات أو تجاوز صلاحيات. أمثلة الشبكات مقصورة على القراءة والتحقق المحلي أو النطاق المصرح به.

## التشغيل السريع

```bash
python3 --version
python3 scripts/001-ip-networking-1.py
```

في Termux:

```bash
pkg update && pkg install python
python scripts/001-ip-networking-1.py
```
